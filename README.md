# Typing-speed-test-game-

PROBLEM STATEMENT-
Typing speed and accuracy are essential skills for students and professionals alike. However, most typing test tools available online are not personalized or available offline for practice. The aim of this project is to develop a console-based Typing Speed Test Game in C that helps users measure and improve their typing skills while demonstrating fundamental programming concepts.

OBJECTIVE-
•  To design and implement an interactive typing test game using the C programming language.
• To calculate and display a user’s typing speed (Words Per Minute) and accuracy.

APPROCH-
Display "Welcome to Typing Speed Test Game!"
Input user name
Display random sentence to type
Start timer
Take user input
Stop timer
Compare input with original text
Calculate WPM and accuracy
Display results
Save data to file
Display leaderboard
The project will be implemented as a modular C program using the following concepts:
•	FUNCTIONS
•	ARRAYS
•	POINTERS 
•	STRUCTURE
•	FILE HANDLING
